# NeuroBite | Corporate Biohacking & Cognitive Nutrition Platform

NeuroBite is a premium B2B corporate wellness subscription platform delivering daily pre-portioned cognitive bento trays (featuring top-tier supplements like Lion's Mane, Omega-3 DHA, Magnesium, essential oils, smart water, and organic raw snacks) to high-performing corporate teams.

## 🌟 Key Features

- **Interactive Bento Tray Anatomy**: 3D hover/click viewer displaying ingredient science and brand certifications (Solgar, Thorne, Ocean, Venatura).
- **Interactive Corporate ROI Calculator**: Real-time slider calculating saved team focus hours and estimated financial return.
- **Interactive QR Code Bio-Routine Portal**: 2-minute parasympathetic Box Breathing timer and 10Hz/14Hz Binaural Alpha wave focus audio player.
- **Corporate Sample Request Form**: B2B lead capture with dietary filter preferences (Vegan, Gluten-Free, Caffeine-Free, Nut-Free).
- **100% English & Fully Responsive**: Sleek dark-mode glassmorphic aesthetics.

## 🚀 Live Demo & Deployment

The application is deployed on GitHub Pages:
- **Live URL**: [https://m-yusufuysal.github.io/NeuroBite/](https://m-yusufuysal.github.io/NeuroBite/)

### GitHub Pages Setup Instructions
1. Navigate to **Repository Settings -> Pages** on GitHub.
2. Under **Build and deployment**:
   - Option A: Set **Source** to **Deploy from a branch** and select Branch: `gh-pages` / Folder: `/ (root)`.
   - Option B: Set **Source** to **GitHub Actions** (the automated `.github/workflows/deploy.yml` workflow will automatically build and publish).

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/m-yusufuysal/NeuroBite.git

# Navigate into directory
cd NeuroBite

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
